# Get Joke Extension

A lightweight Firefox and Chromium extension powered by [JokeAPI](https://v2.jokeapi.dev/).

- Joke categories, five joke languages and Safe mode.
- Punchline reveal, copying, light and dark themes.
- Storage is the only extension permission.

## Development

Node.js 20 or later.

```sh
npm run check
npm run build
```

The build creates Firefox and Chromium packages in `dist/`.
